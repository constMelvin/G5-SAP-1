# SAP-1 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task-by-task.
> **Goal:** Build and verify the DOCX simulator locally.
> **Architecture:** Immutable CPU engine; independent memory parser; React view with cancellable microcycle timer.
> **Tech Stack:** React, TypeScript, Vite, CSS, Vitest, Playwright.
> **Spec:** docs/superpowers/specs/2026-10-31-sap1-design.md

## Global constraints

16 × 8 RAM, 4-bit PC/MAR, 8-bit registers, five required opcodes, user-entered example data, graphical browser interface.

## Review focus

Invalid input must not partially load; reset cancels ticks; HLT prevents mutations; arithmetic and PC wrap; no-HLT programs stay interruptible.
