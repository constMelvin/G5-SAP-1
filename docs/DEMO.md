# Recorded demonstration guide

The silent browser recording is [three-calculations.webm](demo/three-calculations.webm). It enters all three sets of data through the interface, executes each program, shows the resulting LEDs, and resets the machine. It was generated by browser automation; your group can add its own explanation or record a narrated presentation using the walkthrough below.

To regenerate it, start the app with `npm run dev`, install the video encoder with `npx playwright install ffmpeg`, then run `node scripts/record-demo.mjs`. Set `PLAYWRIGHT_CHANNEL=msedge` if using installed Edge instead of Playwright Chromium.

Start with `npm install` and `npm run dev`, then open the displayed URL.
For a narrated presentation, record the browser window using your recording software and explain the steps below.

## Explain the architecture

Point out PC, MAR, RAM, IR, accumulator, adder/subtractor, B register, output register, shared W-bus and controller signals. Explain that eight-bit arithmetic wraps and addresses are four bits.

## Three demonstrations

Click **Insert instruction template**. This inserts LDA 9H, ADD AH, SUB BH, OUT, HLT at 0–4. It does not fill in the data.
Manually type each case into memory 09, 0A and 0B, then click **Load program**.

| Case       | 09 / A | 0A / B | 0B / C | Calculation     | Expected output |
| ---------- | ------ | ------ | ------ | --------------- | --------------- |
| Assignment | 25H    | 05H    | 23H    | 25H + 05H − 23H | 07H / 00000111  |
| Second     | 12H    | 08H    | 05H    | 12H + 08H − 05H | 15H / 00010101  |
| Third      | 40H    | 10H    | 20H    | 40H + 10H − 20H | 30H / 00110000  |

For the first case use **Clock** to explain fetch (PC→MAR, PC increments, RAM→IR), then **Step instruction** to finish LDA. Show accumulator 25H.
Use **Run** for the rest; show Halted, hex output 07 and the LED bits.
For the remaining cases type the new values and load again. Show each result and explain OUT.
Finally demonstrate **Reset**, which zeros the registers and restores the most recently loaded program.
